More money is not always a better life.

A heat-stressed planting trial can fail. An extra shift earns money but uses recovery time. These illustrative outcomes are separate from curriculum completion and assessed employability.

The trial always fails in this test scenario so the recovery path can be checked. Reflection identifies missing shade; a free supported retry adds it. This records a practice insight, not proof of mastery. Each option runs once per reset.
