# Approved dimensional employability icons

The exclusive approved v3 family: six parents and 21 subsets, using the supplied 256px transparent WebP exports unchanged. Total image payload: 383,746 bytes. `manifest.json` records each stable category/subskill ID, original number, label and approved SHA-256.

The dashboard maps by category and subskill ID, rather than display-array position. Existing taxonomy order, labels, descriptions, STAR evidence, points and saved data are unchanged. Original numbering is retained; there is no Digital Literacy 2.2.

Subset artwork contains its exact parent badge at bottom-right. Cards retain adjacent accessible labels and use 64px subset images. Images use browser lazy loading and async decoding. The 3D game does not import or preload this family; it is requested when existing dashboard/portfolio screens need it.

The source PNG and larger WebP exports remain in the approved source package. No new illustration, conversion or garment/model work is included.
