# External Animation Pack

Use this pack when creating the ECC avatar animations in specialist animation software or an AI video tool.

Start here:

- `avatar-animation-brief.md`: plain-English production brief for an animator or tool operator.
- `ai-video-prompts.json`: structured prompt pack for ElevenLabs Image & Video, Runway, Kling, Veo, Pika, or similar image-to-video tools.

Reference images already in this repo:

- `../layers/ecc-boy-base-neutral/recomposed-preview.png`
- `../layers/ecc-girl-base-neutral/recomposed-preview.png`

Best target workflow:

1. Use the reference images for character consistency.
2. Generate or hand-animate short motion clips.
3. Export clean loops for idle, walk, run, jump, wave, point, think, and celebrate.
4. For the game, convert final animations into sprite sheets, Rive, Spine, Lottie, or transparent WebM depending on the chosen pipeline.
