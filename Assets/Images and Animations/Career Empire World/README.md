# Career Empire World Approved Assets

This folder is for approved production assets from the Career Empire World asset register.

Use the filenames listed in:

- `docs/career-empire-world-asset-register.md`
- `data/world/asset-register.json`

Do not save contact sheets, concept boards, or rejected drafts here. Only approved game-ready assets should live in this folder.

Subfolders:

- `terrain/`
- `paths/`
- `water/`
- `buildings/`
- `transformations/`
- `avatars/`
- `props/`
- `fx/`
