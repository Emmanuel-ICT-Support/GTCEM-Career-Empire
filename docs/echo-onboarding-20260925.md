## Creating/importing the asset
The source is createEchoModel in playable-3d/echo-guide.js. Echo-review.glb is an exported static geometry/material asset, intended for Blender import and offline refinement. Preserve the native source and original concept provenance. Model full 3D silhouette, keep sprout/crown/root detail, origin at ground and roughly 0.8m overall height. Use a small number of materials, a single restrained transparent shell and emissive face/roots; avoid layered refraction or a large texture atlas. Keep visible detail at normal gameplay scale. Proposed future budget: under 10k triangles and under 500KB when practical; these are targets, not engine limits.

If importing a refined GLB, use the already bundled GLTFLoader once after first paint, validate finite bounds and scale, attach it to the existing visual root, and retain this native mesh as fallback. Keep bob/orbit as node transforms; add skeletal animation only for a specific required gesture and validate on its own rig. Do not add Echo to the player profile catalogue. Recheck transparency, phone framing, reduced motion, clicking and failure recovery after replacement. The static export has no baked animation and is not claimed as a rigged avatar.
