## Data and limits

Existing version3 event log supports optional initiative-action, initiative-recognition and initiative-retrieval events. Old events/revisions decode unchanged. Events distinguish learner-chosen simulation opportunities from hinted practice; they do not prove unprompted real work. Plan changes alone create no five-behaviour evidence. Recognition records visible-option attempts; retrieval is explicitly self-reported with model reveal, not collected/assessed independent answers. `initiativeProgress` returns five exact curriculum-keyed rows with separate experience, action practice, recognition and uncued-list status; mastery remains unverified. This is a reusable data seam, not a whole-course tracker.

Safety/role/training boundaries and retaining current duties are valid choices. Existing guest reset/session/account rules remain untouched; no cross-session or new login integration claim.
